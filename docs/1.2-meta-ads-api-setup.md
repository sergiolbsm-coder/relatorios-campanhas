2. Tipo de app: **"Empresa" (Business)**
3. Nome do app: `Analise de Campanhas` (ou o nome que preferir)
4. E-mail de contato: sergiolbsm@gmail.com
5. Portfólio de negócios: selecione o Business Manager do Passo 0 (se

2. Adicione **Marketing API**

## Passo 3 — Garantir que o app enxerga as contas certas

1. Em https://business.facebook.com/settings/system-users (dentro do
   Business Manager anotado no Passo 0), crie um **usuário do sistema**
   (System User) — vantagem: o token dele **não expira**, diferente do
   token de usuário comum (60 dias). Nome sugerido: `analise-campanhas-bot`,
   função: **Admin** (ou Employee, se preferir restringir depois).
2. Em **Adicionar ativos**, atribua ao usuário do sistema:
   - As 3 contas de anúncio da tabela acima (com no mínimo permissão de
     "Análise/Visualizar dados")
   - As 3 contas do Instagram (via as Páginas do Facebook conectadas a
     cada perfil — o Instagram Insights depende da Página vinculada)
3. Em **Adicionar apps**, vincule o app `Analise de Campanhas` criado no
   Passo 1 a esse usuário do sistema

`[ ]` System user criado com acesso às 3 contas de anúncio + 3 perfis do Instagram.

## Passo 4 — Gerar o token de acesso

Ainda na tela do System User (business.facebook.com/settings/system-users):

1. Clique em **Gerar novo token**
2. Selecione o app `Analise de Campanhas`
3. Marque as permissões:
   - `ads_read`
   - `read_insights`
   - `instagram_basic`
   - `instagram_manage_insights`
   - `pages_read_engagement`
   - `business_management`
4. Clique **Gerar token** e copie o valor **imediatamente** (a Meta só
   mostra uma vez)

`[ ]` Token colado no `.env`:
```
META_ACCESS_TOKEN=<cole aqui>
```

> **Por que System User e não o token "rápido" do Graph API Explorer?**
> O token do Graph API Explorer (ou de um login OAuth comum) expira em no
> máximo 60 dias e precisa de renovação manual. O token de System User não
> expira — essencial para um pipeline que roda sozinho todo dia (Fase 2.7).
> Se você quiser só testar rapidinho antes de configurar tudo isso, pode
> gerar um token temporário em
> https://developers.facebook.com/tools/explorer/ (selecione o app, as
> mesmas permissões acima, e clique "Generate Access Token") — mas troque
> pelo token do System User antes de automatizar.

## Passo 5 — Validar o token

Teste rápido pra confirmar que o token enxerga a conta certa (troque
`SEU_TOKEN` pelo valor gerado e `act_297372404548129` pela conta que quiser
testar):

```bash
curl -s "https://graph.facebook.com/v21.0/act_297372404548129/insights?fields=impressions,clicks,spend&access_token=SEU_TOKEN"
```

Se voltar um JSON com `data: [...]` (mesmo que vazio, se não houver
atividade recente), o token está funcionando. Se voltar `"error"`, o texto
do erro geralmente diz exatamente qual permissão ou acesso está faltando.

`[ ]` Teste validado para ao menos 1 das 3 contas de anúncio.

## Sobre App Review

Como as 3 contas de anúncio e os 3 perfis do Instagram já são administrados
por você (mesmo Business Manager do app), a Meta libera acesso em modo
**Standard** sem exigir App Review público — isso só é necessário se o app
fosse usar dados de contas de terceiros fora do seu Business Manager. Não é
o caso aqui, então não deve haver bloqueio de aprovação como aconteceu com
o developer token do Google Ads.

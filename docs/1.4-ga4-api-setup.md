# 1.4 — Google Analytics Data API (GA4)

Checklist para fechar o item 1.4. Boa notícia: esse é mais simples que o
Google Ads — usa **service account**, que não passa pela tela de
consentimento OAuth (sem risco de repetir os erros `org_internal` /
`access_denied` que tivemos no 1.1).

## Passo 1 — Ativar a API

1. No mesmo projeto do Google Cloud que você já usa (`campanha-instituto`),
   acesse:
```
https://console.cloud.google.com/apis/library/analyticsdata.googleapis.com
```
2. Clique **Ativar**

`[ ]` Google Analytics Data API ativada.

## Passo 2 — Criar a service account

1. Acesse:
```
https://console.cloud.google.com/iam-admin/serviceaccounts
```
2. Clique **Criar conta de serviço**
3. Nome: `ga4-analise-campanhas`
4. Não precisa conceder papéis (roles) do projeto — o acesso vai ser dado
   diretamente dentro do GA4, não no Cloud Console
5. Clique **Concluir**

`[ ]` Service account criada. Anote o **e-mail** dela — algo como
`ga4-analise-campanhas@campanha-instituto.iam.gserviceaccount.com`.

## Passo 3 — Gerar a chave JSON

1. Na lista de contas de serviço, clique na que você acabou de criar
2. Aba **Chaves** → **Adicionar chave** → **Criar nova chave** → tipo **JSON**
3. Um arquivo `.json` vai baixar automaticamente no seu computador

`[ ]` Mova esse arquivo pra dentro do projeto, na pasta `secrets/` (já está
no `.gitignore`, não vai pro Git):
```bash
mkdir -p /Users/sergiomoura/Claude/analise-campanhas/secrets
mv ~/Downloads/campanha-instituto-*.json /Users/sergiomoura/Claude/analise-campanhas/secrets/ga4-service-account.json
```

## Passo 4 — Dar acesso à service account dentro do GA4

Esse é o passo que substitui o "OAuth" — sem ele a API nega acesso mesmo com
a chave certa.

1. Acesse https://analytics.google.com
2. Confirme que está na propriedade certa: **Instituto da Liderança (Moura)**,
   ID `450305882` (cuidado pra não confundir com a outra propriedade parecida,
   `379676291` — ver nota no `config.yaml`)
3. **Admin** (ícone de engrenagem, canto inferior esquerdo) → na coluna
   **Propriedade** → **Acesso à propriedade** (Property Access Management)
4. Clique **+** → **Adicionar usuários**
5. Cole o e-mail da service account do Passo 2
6. Papel: **Visualizador** (Viewer) — é suficiente pra leitura de relatórios
7. Clique **Adicionar**

`[ ]` Service account com acesso Viewer confirmado na propriedade 450305882.

## Passo 5 — Validar o acesso

```bash
cd /Users/sergiomoura/Claude/analise-campanhas
source .venv/bin/activate
pip install google-analytics-data
export GA4_SERVICE_ACCOUNT_JSON_PATH=./secrets/ga4-service-account.json
python3 etl/scripts/test_ga4_access.py 450305882
```

Se voltar linhas com sessões/usuários dos últimos dias, está funcionando.

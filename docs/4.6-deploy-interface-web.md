# Publicar a interface web (GitHub + Render)

Mesmo padrão do projeto sipat-quiz: essa máquina não tem `gh` CLI nem SSH
configurado pro GitHub, então o upload é manual pela interface web do
GitHub. Depois disso, o Render conecta direto no repositório.

## Passo 1 — Criar o repositório no GitHub

1. Acesse https://github.com/new
2. Nome sugerido: `relatorios-campanhas` (ou o que preferir)
3. Deixe **privado** — o repo vai ter estrutura de credenciais, mesmo que
   os valores reais não sejam commitados
4. Não marque "Add a README" (o projeto já tem um)
5. Clique **Create repository**

`[ ]` Repositório criado.

## Passo 2 — Subir o código

Na tela que aparecer depois de criar, GitHub mostra um bloco "…or push an
existing repository from the command line". Rode esses comandos no
Terminal (ajuste a URL pro seu usuário/repo):

```bash
cd /Users/sergiomoura/Claude/analise-campanhas
git remote add origin https://github.com/SEU_USUARIO/relatorios-campanhas.git
git branch -M main
git push -u origin main
```

Se pedir login e você não tiver `gh`/token configurado, o jeito mais
simples é fazer upload manual pela própria página do GitHub:
1. Na página do repositório vazio, clique em **uploading an existing file**
2. Arraste a pasta do projeto (ou use "Add file → Upload files" e selecione
   tudo, exceto `.venv/`, `secrets/`, `.env`, `etl/data/`, `db/*.db` — esses
   já ficam de fora automaticamente se você zipar/arrastar sem essas pastas)

`[ ]` Código no GitHub.

## Passo 3 — Criar o serviço no Render

1. Acesse https://dashboard.render.com
2. **New +** → **Web Service**
3. Conecte sua conta GitHub (se ainda não conectou) e selecione o repo
   `relatorios-campanhas`
4. O Render deve detectar o `render.yaml` automaticamente e sugerir os
   valores (nome, build/start command) — confirme

`[ ]` Serviço criado (ainda sem rodar — falta preencher as variáveis).

## Passo 4 — Preencher as variáveis de ambiente

Na tela do serviço → **Environment**, adicione cada uma (o `render.yaml`
já lista os nomes, o Render deve pedir os valores no primeiro deploy):

**Senhas de acesso** (invente valores fortes, tipo senha mesmo):
```
FLASK_SECRET_KEY=<qualquer string aleatória longa>
ADMIN_PASSCODE=<senha do time>
PASSCODE_ASSOCIACAO_LUTO_UNIAO=<senha só pra esse cliente>
PASSCODE_INSTITUTO_DA_LIDERANCA=<senha só pra esse cliente>
PASSCODE_TRAINER_SERGIO_MOURA=<senha só pra esse cliente>
```

**Credenciais de API** — copie os valores do seu `.env` local
(`analise-campanhas/.env`, arquivo que nunca foi pro Git):
```
GOOGLE_ADS_CLIENT_ID
GOOGLE_ADS_CLIENT_SECRET
GOOGLE_ADS_REFRESH_TOKEN
GOOGLE_ADS_DEVELOPER_TOKEN
GOOGLE_ADS_LOGIN_CUSTOMER_ID
META_APP_ID
META_APP_SECRET
META_ACCESS_TOKEN
```

`[ ]` Todas as 13 variáveis preenchidas.

## Passo 5 — Deploy

O Render já deve começar o deploy sozinho depois de salvar as variáveis.
Acompanhe em **Logs** — procure por `Booting worker` ou similar indicando
que o `gunicorn` subiu. O link fica em algo como
`https://relatorios-campanhas.onrender.com`.

`[ ]` Deploy concluído, site abrindo a tela de login.

## Passo 6 — Testar

1. Abra o link, entre com `ADMIN_PASSCODE`
2. Escolha uma marca, gere um relatório (~30-90s no plano gratuito — pode
   ser mais lento na primeira vez do dia, o Render "dorme" o serviço
   gratuito após inatividade e demora uns 30-50s pra acordar)
3. Confirme que o PDF baixa certo

`[ ]` Teste ponta a ponta ok.

---

## Nota sobre o plano gratuito do Render

O plano free "dorme" o serviço depois de um tempo sem uso — a primeira
requisição depois disso demora bem mais (acordar + gerar o relatório pode
passar de 2 minutos). Se isso incomodar o cliente, o plano pago mais barato
(Starter, ~US$7/mês) mantém sempre ativo. Dá pra trocar depois, sem
reconfigurar nada — só mudar o plano na aba **Settings** do serviço.

## Como adicionar um cliente novo depois

1. Adicione a marca em `config.yaml` (já é o processo normal do projeto)
2. Crie uma env var nova no Render: `PASSCODE_<CHAVE_DA_MARCA_EM_MAIUSCULO>`
3. Pronto — o painel admin já lista a marca nova automaticamente, e o link
   de cliente funciona assim que a senha for cadastrada
